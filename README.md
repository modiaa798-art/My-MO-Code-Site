## 🎯 القصة باختصار

منصة **كوريو** بتدرّس JavaScript كويس — بس الأسئلة اللي جوّاها **قليلة، سهلة، ومتكررة.**

**Birmaja** اتعملت عشان تكمّل النقص ده.

هي لعبة مراجعة بتحطك في تحدي حقيقي: أسئلة أكتر بمستويات صعوبة مختلفة، ووقت محدود، ونظام XP — **عشان تراجع أكتر وتزهق أقل.**

---

## 👤 مناسبة إزاي لطلاب كوريو؟

✅ **تراجع** المحتوى اللي اتعلمته في كوريو قبل الامتحانات  
✅ **تتدرب** على أسئلة أكتر وأصعب من اللي في المنصة  
✅ **تتسلى** بين المذاكرة بدل ما تمل وتوقف  
✅ **تتابع تقدمك** وتشوف فين نقاط ضعفك موضوع بموضوع
